# House Price Prediction Model

A Machine Learning project using Linear Regression to predict house prices.

## Features
- Data Cleaning
- Feature Engineering
- Linear Regression
- R² Score Evaluation
- Streamlit Web App

## Tech Stack
Python, Pandas, NumPy, Scikit-Learn, Streamlit

## Run Project

pip install -r requirements.txt

python model_training.py

streamlit run app.py
