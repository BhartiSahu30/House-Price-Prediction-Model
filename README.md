# House Price Prediction Model 🏠

This project is a Machine Learning based House Price Prediction System developed using Python and popular data science libraries.

## 📌 About the Project
The model predicts house prices based on different features such as area, number of rooms, location factors, and other housing attributes.

This project was developed as part of the AI/ML Internship at Axcentra.

---

## 🚀 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

## 📊 Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis
- Model Training
- House Price Prediction
- Data Visualization

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/BhartiSahu30/House-Price-Prediction-Model.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the project

```bash
python model_training.py
 streamlit run app.py
```
